00 — Foundations

Bold, playful, game-like — built for serious study.

Merit is a gamified exam-prep platform for Sri Lankan O/L and A/L students. The look is neo-brutalist: flat saturated color blocks, solid black outlines on everything, and hard offset shadows with zero blur. It feels like a sticker sheet, an arcade, and a study planner at once.

Three pillars on every screen

1

Outlined & chunky

Black borders and hard shadows give every element physical, tactile weight.

2

Gamified

Streaks 🔥, merit points 🪙, tiers, starbursts, leaderboards and progress everywhere.

3

Tri-lingual & local

EN / SI / TA toggles are first-class; content is Sri-Lanka specific.

Voice

Confident, encouraging, short. Never corporate, never condescending. Emoji are on-brand but used sparingly as functional accents (🔥 streak · 🪙 points · ★ rating · ⚡ energy).

"Keep your streak alive." "Earn it." "Hit your weak spots first."

// pubspec.yaml bundles local files (assets/google_fonts/ is just a folder
// name — nothing loads from Google Fonts). Use the family names directly;
// do NOT use the google_fonts package.
//   ClashDisplay     → w500, w600, w700
//   PlusJakartaSans  → w400, w500, w600, w700
// In app code prefer Theme.of(context).textTheme / MeritTypography.*
class MeritType {
  static const display = 'ClashDisplay';
  static const body = 'PlusJakartaSans';
  static TextStyle clash(double size, {FontWeight w = FontWeight.w700, Color? c}) =>
      TextStyle(fontFamily: display, fontSize: size, fontWeight: w,
                letterSpacing: size >= 64 ? -size * 0.04 : -size * 0.02,
                height: 1.0, color: c);
  static TextStyle text(double size, {FontWeight w = FontWeight.w500, Color? c}) =>
      TextStyle(fontFamily: body, fontSize: size, fontWeight: w, height: 1.5, color: c);
}

/// The Merit "sticker box": black border + hard offset shadow, NO blur.
BoxDecoration meritBox({
  Color fill = MeritColors.white, double radius = 18, double offset = 4,
  Color border = MeritColors.line, Color? shadow,
}) => BoxDecoration(
  color: fill,
  borderRadius: BorderRadius.circular(radius),
  border: Border.all(color: border, width: 2),
  boxShadow: [
    BoxShadow(color: shadow ?? MeritColors.line,
              offset: Offset(offset, offset), blurRadius: 0), // blurRadius:0 is mandatory
  ],
);
// Selected / focused: accent border + accent shadow
final selected = meritBox(border: MeritColors.purple, shadow: MeritColors.purple);

Widget meritButton(String label, {VoidCallback? onTap,
    Color fill = MeritColors.purple, Color fg = Colors.white, bool arrow = true}) {
  return GestureDetector(
    onTap: onTap,
    child: Container(
      padding: const EdgeInsets.symmetric(horizontal: 22, vertical: 14),
      decoration: meritBox(fill: fill, radius: 99, offset: 4),
      child: Row(mainAxisSize: MainAxisSize.min,
        children: [
          Text(label, style: MeritType.clash(15, c: fg)),
          if (arrow) Padding(padding: const EdgeInsets.only(left: 8),
            child: Text('→', style: MeritType.clash(15, c: fg))),
        ]),
    ),
  );
}

12 — Patterns

Logo usage

A 3-color isometric cube inside a pyramid. It carries its own outline, so it works on cream, white, ink and purple. Pair the mark with the wordmark "Merit Project" in Clash Display, uppercase, letter-spacing:.04em.

On cream
On white
On ink
On purple

✓ Do

  • Pair with the Clash Display wordmark, uppercase, .04em tracking.
  • Use on cream, white, ink or purple — it carries its own outline.
  • Keep clear space of at least one cube-width around it.

✕ Don't

  • Recolor, rotate, or add effects / drop-shadows to the mark.
  • Stretch, skew, or change the cube proportions.
  • Place on a busy photo or a low-contrast tint.
